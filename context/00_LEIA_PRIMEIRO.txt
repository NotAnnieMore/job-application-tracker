JOB APPLICATION TRACKER
GUIA INICIAL DO PROJETO

Este conjunto de ficheiros serve como base para desenvolver, passo a passo, uma aplicação full-stack para gestão de candidaturas de emprego.

Objetivo deste guia:
- Definir claramente o que queremos construir.
- Evitar começar a programar sem decisões mínimas tomadas.
- Dividir o projeto em fases pequenas e verificáveis.
- Usar o Codex como apoio, sem perder a compreensão do código.
- Permitir alterações de âmbito e design ao longo do desenvolvimento.
- Registar decisões para que o projeto continue coerente.

Princípios de trabalho:
1. A aplicação começa em português de Portugal.
2. Cada funcionalidade deve ser discutida antes de ser implementada.
3. O Codex deve trabalhar em tarefas pequenas e concretas.
4. Cada alteração deve ser revista, testada e explicada.
5. Recomendações técnicas podem surgir ao longo do projeto.
6. Nenhuma recomendação deve ser aplicada automaticamente se alterar o âmbito, o design ou a experiência de utilização.
7. Devemos privilegiar uma versão funcional e bem concluída antes de acrescentar funcionalidades avançadas.
8. O projeto deve ficar suficientemente claro para ser explicado numa entrevista.

Ordem recomendada de leitura:
1. 01_OBJETIVO_E_ESCOPO.txt
2. 02_ETAPAS_DO_PROJETO.txt
3. 03_DECISOES_DE_DESIGN.txt
4. 04_ESTRUTURA_DE_PASTAS.txt
5. 05_REGRAS_PARA_TRABALHAR_COM_CODEX.txt

Resultado esperado:
Uma aplicação privada, responsiva e organizada, onde cada utilizador possa gerir empresas, recrutadores, oportunidades, candidaturas, entrevistas, notas, próximas ações e estatísticas.
